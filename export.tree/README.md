# ZAP repeated-session resting EEG and TMS-evoked EEG

BrainVision resting-state EEG (task-rest) and TMS-evoked EEG (task-tep) in pre/post acquisitions across sessions.

The acq-01pre and acq-02post labels encode acquisition order.
MEPpre, MEPpost5 and MEPpost25 original .txt files are preserved under sourcedata/; they are not yet validated EMG-BIDS files.

Before sharing: verify EEG reference and filters, stimulation event codes, study description, ethical approval, licence, and that recordings contain no identifying information.
